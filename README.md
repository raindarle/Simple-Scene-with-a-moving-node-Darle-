# Simple Scene with a Moving Node (Darle - F Sat (4:30 PM - 7:00 PM)

## Description
This beginner-level Godot project demonstrates a **2D “Hello World” label** moving horizontally across the screen.

**Extra features:**
- The label **shakes slightly** when it hits the left or right edges.  
- **Movement speed** and **shake effect** are adjustable via the Inspector.

## Project Files
- `hello_world.gd` – GDScript controlling label movement and shake.  
- `main.tscn` – Main scene with the Label node.  
- `icon.svg` – Project icon.  
- `project.godot` – Project configuration.  

*(Other files like `.import` and `.gd.uid` are auto-generated by Godot.)*

## Features
- Moving “Hello World” label.  
- Edge collision detection with bounce.  
- Shake effect on impact.

# Week 2 : Activity 1 - Gameplay Mechanics (Darle - F Sat (4:30 PM - 7:00 PM)

## Description

# Week 2 : Activity 2 - Level Design (Darle - F Sat (4:30 PM - 7:00 PM)

## Description

This Week 2 Godot project demonstrates 2D level design using TileMaps, hazards, and difficulty progression.

The game features two designed levels inside the main scene, built using grid-based TileMaps from the Brackeys Platformer Assets pack.

The objective is simple:

- Avoid traps.

- If the player touches a spike or enters the killzone, the level restarts.

- There is no HP system — one hit immediately restarts the level.

Level 1 is intentionally easier, while Level 2 increases difficulty through tighter spacing and more traps.


## Project Files

player.gd – GDScript controlling movement, gravity, and jumping.
killzone.gd – Script handling hazard collision detection.
player.tscn – Player scene.
game.tscn – Main game scene.
killzone.tscn – Hazard area scene.
project.godot – Project configuration.
spike.tscn – Spike trap scene used as hazard obstacles.
icon.svg – Project icon.

(Other files like .import and .uid are auto-generated by Godot.)


 ## Features

Left and right movement using keyboard input.
Jump mechanic with gravity physics.
Collision detection with floor and platforms.
Killzone hazard detection.
Spikes brings player back from level start.
